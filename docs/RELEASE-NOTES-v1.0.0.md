## 学习通作业中心 v1.0.0

首个可用版本：把「学习通（超星）」分散在各门课里的未交作业与待参加考试，汇总到一个自托管的看板上，并按剩余时间分级提醒。

### 亮点

- **一次登录，全局待办**：自动遍历所有课程，作业与考试统一呈现（课程、任务、截止、剩余时长、状态）。
- **点开就能读题**：作业详情抽屉展示大题结构、题干、选项、分值与附件，不需要跳回学习通。
- **不刷屏的提醒**：新任务即时提醒，剩余 72h / 24h / 3h 各一次，逾期一次，另加每日汇总。
- **可以忽略**：不关心的任务一划了之，统计与推送同步生效，随时恢复。
- **自带网页面板**：倒计时、筛选搜索、连接诊断、运行日志、在线配置，访问口令保护。
- **也能纯命令行跑**：`python -m cxreminder run` 常驻轮询，适合放服务器上。

### 修复的坑

- 作业/考试列表接口需要**课程级 `enc` 令牌**（课程页隐藏域 `workEnc` / `examEnc` / `openc`），否则一律「无权限的操作」；
- 详情页 `typeName` 位于 `id="question"` 之前，按 id 切块会把下一题的题型算到当前题上。

### 安装

```bash
git clone https://github.com/shiliu153/chaoxing-homework-hub.git
cd chaoxing-homework-hub/chaoxing-web
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

首次启动会生成访问口令（`data/web_password`），登录后在「设置」里填学习通账号即可。

### 说明

仅用于整理你自己账号的待办，请遵守学校规定与平台服务条款。仓库内不含任何账号凭据。
